# Recall

## Procedure

1. Read the index in `memory/README.md`.
2. Read only the applicable topic files.
3. If the index does not help, search all of `memory/` for keywords.
4. Give the information to the user, or use it in the task.

## Rules

- Do not read all files in `memory/` if the index is sufficient.
- If two entries do not agree, use the newer entry. Tell the user about the difference.
