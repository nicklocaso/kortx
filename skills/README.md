# Skills

Each skill is one folder with a `SKILL.md` file.
The files use the Agent Skills format.

## Index

| Skill | Use it to |
| --- | --- |
| `commit` | Make a git commit. |
| `write-docs` | Write documentation and messages in ASD-STE100. |
| `new-project` | Add a project or a child unit to `projects/`. |
| `remember` | Save important information to `memory/`. |
| `recall` | Find information in `memory/`. |
| `new-skill` | Add a skill, or change the rules of a skill or a contract. |
| `backlog` | Add, change, complete or show the tasks of a project. |
| `new-job` | Add or change a recurring job in a project. |

## Rules

- Give each skill one task only.
- Use kebab-case for skill names.
- Update this index when you add, change or remove a skill.
